# Entity Profiles

> Centralised entity research for the SPO Incentives analysis.
> This material is referenced from multiple sub-flow reports —
> operator-delegator distribution, pools distribution, and the main report.
>
> Last updated: 2026/04/07.

## Sources

The profiles consolidate and extend two earlier artefacts:

- `sub-flows/pools-distribution/mainnet-analysis/docs/mpo_entity_profiles.md`
  — narrative profiles grouped by archetype (CEX, IVaaS, Platform, Independent MPO, Ecosystem Steward), with historical stake trajectory and pledge-coverage ratio. Epoch 618.
- `sub-flows/pools-distribution/mainnet-analysis/data/mpo_entity_archetypes.csv`
  — machine-readable archetype classification with reasoning.

This folder enriches those profiles with web research (business model, product
surface, public documentation) and extends coverage to entities that appear
across the strategy × margin matrix in the operator-delegator analysis.
