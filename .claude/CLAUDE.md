# CLAUDE.md

This repository is part of the `stream-SPO` workspace.

Apply the shared workspace rules from `../../.claude/rules/`, then use the
repo-specific guidance below.

## Project: spo-incentives

- Main report source: `spo_incentives/report.tex`
- Scenario-analysis workspace: `scenarii-evaluation/`
- Generated or derived artefacts usually live in
  `scenarii-evaluation/outputs/`, `scenarii-evaluation/figures/`, and fetched
  data files under `scenarii-evaluation/data/`

## Key Conventions

- Keep report edits targeted. Avoid broad LaTeX reformatting unless the task is
  formatting.
- Prefer changing analysis scripts before manually editing generated outputs.
- Preserve authorship, acknowledgements, and established report tone unless the
  user explicitly asks to change them.
